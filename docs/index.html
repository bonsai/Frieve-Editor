Frieve Editor

Idea processor for complex thoughts and structured notes.

A Windows desktop application for thinking in cards, links, and layered outlines. This GitHub Pages site mirrors the project overview and download instructions.

Download release Source repository

What it is

An idea processor to help you think and conceive very complex thoughts and ideas.

Platform

Runs on Windows. Build instructions are provided in the repository for C++ Builder.

Install

Download the latest release ZIP, unzip it, and run the executable. No installer is required.

Build

Open src/feditor.cbprpj in C++ Builder or use build_project.bat.

Documentation

The repository contains a detailed format specification in docs/FIP2_FORMAT_SPEC.md and the project README includes both English and Japanese usage notes.
